# ⏱️ Calculadora de Jornada de Trabalho

> Ferramenta web responsiva e gratuita para simulação de readequação de escalas de trabalho (metas de 40h e 42h semanais), desenvolvida para escritórios de contabilidade, departamentos pessoais (DP) e empresas.

---

## 🚀 Sobre o Projeto

Com as discussões e acordos coletivos voltados para a redução da jornada de trabalho no Brasil, a **Calculadora de Jornada** foi criada para simplificar o cálculo de redistribuição de horas trabalhadas sem a necessidade de processamento em servidores backend.

A ferramenta opera 100% no front-end, garantindo velocidade, privacidade nos dados inseridos e fácil utilização.

### 🌟 Funcionalidades
- **Modo Padrão (Geral):** Ajuste rápido para jornadas uniformes de 5 ou 6 dias semanais.
- **Modo Detalhado (Por Dias):** Permite configurar blocos de dias com jornadas distintas (ex: Segunda a Quinta um horário e Sexta outro).
- **Opções de Adequação:**
  - Ajuste no horário de entrada.
  - Ajuste no horário de saída (largada).
  - Ampliação do intervalo de almoço (intrajornada).
- **Flexibilidade de Cenários:** Opções para concentrar a redução no bloco principal de dias ou distribuir proporcionalmente por toda a semana.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** & **JavaScript ES6+** (Lógica de cálculo cliente-side)
- **Tailwind CSS v4** (Interface responsiva e minimalista)
- **SEO & Open Graph** (Otimizado para motores de busca e compartilhamento)
